# Week 1: Introduction to LLMs and Transformers

## Overview
This week covers the fundamentals of Large Language Models and the Transformer architecture.

## Topics Covered
- Introduction to Generative AI and LLMs
- Transformer Architecture
- Self-Attention Mechanism
- Tokenization and Embeddings
- Pre-training and Model Scaling

## Assignments

### Assignment 1: Exploring Pre-trained Models
- **Objective**: Get familiar with using pre-trained LLMs
- **Notebook**: `assignment1_exploring_llms.ipynb`
- **Key Tasks**:
  - Load and use a pre-trained model from Hugging Face
  - Experiment with different prompts
  - Compare model outputs
  - Understand tokenization

### Lab 1: Transformer Architecture
- **Objective**: Understand the components of transformer models
- **Notebook**: `lab1_transformer_basics.ipynb`
- **Key Tasks**:
  - Visualize attention mechanisms
  - Explore model architecture
  - Experiment with different model sizes
